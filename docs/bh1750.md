# BH1750 Luminance

Reads ambient light (illuminance, lux) from a ROHM BH1750 over I2C. Shares the library I2C bus.

**Platforms:** `esp32` `esp32s2` `esp32s3` `esp32c3` `esp32c6`

**Requires:** i2c

## Entities

| Domain | Name |
|---|---|
| `sensor` | Illuminance |

## Usage

Local include (repo checked out beside your config):

```yaml
packages:
  bh1750: !include
    file: esphome_sensor_templates/templates/environment/bh1750.yaml
    vars: { st_update_interval: 60s }
```

Remote include (pulled straight from GitHub):

```yaml
packages:
  bh1750: github://OWNER/esphome_sensor_templates/templates/environment/bh1750.yaml@main
```

> Replace `OWNER` with the GitHub owner/repo that hosts this library.

## Variables

| Variable | Default | Description |
|---|---|---|
| st_update_interval | `60s` | How often to sample the sensor |
| st_name_prefix | `""` | Prefix prepended to the entity name |
| st_disabled_by_default | `false` | Ship the entity disabled in HA |
| st_internal | `false` | Hide the entity from HA/web entirely |
| st_state_class | `measurement` | state_class for the reading; set "" to opt out of HA long-term statistics |
| st_bh1750_i2c_id | `st_i2c_bus` | id of the I2C bus to use (from core/i2c.yaml) |
| st_bh1750_address | `0x23` | I2C address (0x23 ADDR->GND/floating, 0x5C ADDR->VCC) One of: `0x23`, `0x5C`. |

## Notes

- Requires the shared I2C bus - include core/i2c.yaml. The component picks measurement resolution automatically based on light level.
- Common breakout is the GY-302. Range roughly 1-65535 lx; direct sunlight saturates the high end.
