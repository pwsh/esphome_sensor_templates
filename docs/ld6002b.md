# LD6002B 3D mmWave Presence

HiLink HLK-LD6002B 60GHz mmWave radar with 3D (X/Y/Z) multi-target tracking over UART. Exposes occupancy, the active target count and the first target's 3D position. Owns its own uart: bus.

**Platforms:** `esp32` `esp32s2` `esp32s3` `esp32c3` `esp32c6`

**Requires:** none

## Entities

| Domain | Name |
|---|---|
| `binary_sensor` | Presence |
| `sensor` | Target Count |
| `sensor` | Target 1 X |
| `sensor` | Target 1 Y |
| `sensor` | Target 1 Z |

## Usage

Local include (repo checked out beside your config):

```yaml
packages:
  ld6002b: !include
    file: esphome_sensor_templates/templates/presence/ld6002b.yaml
    vars: { st_name_prefix: "", st_ld6002b_uart_tx_pin: <value>, st_ld6002b_uart_rx_pin: <value> }
```

Remote include (pulled straight from GitHub):

```yaml
packages:
  ld6002b: github://OWNER/esphome_sensor_templates/templates/presence/ld6002b.yaml@main
```

> Replace `OWNER` with the GitHub owner/repo that hosts this library.

## Variables

| Variable | Default | Description |
|---|---|---|
| st_name_prefix | `""` | Prefix prepended to every entity name |
| st_disabled_by_default | `false` | Ship the entities disabled in HA |
| st_internal | `false` | Hide the entities from HA/web entirely |
| st_state_class | `measurement` | state_class for the numeric sensors; set "" to opt out of HA long-term statistics |
| **st_ld6002b_uart_tx_pin** | **(required)** | GPIO wired to the sensor RX pin (ESP TX) |
| **st_ld6002b_uart_rx_pin** | **(required)** | GPIO wired to the sensor TX pin (ESP RX) |

## Notes

- Requires ESPHome 2026.8.0+ (component added in 2026.8).
- Unlike the 24GHz LD2410/LD2450, the LD6002B is a 60GHz (58-64GHz) radar that reports true 3D target coordinates (X/Y/Z in metres) rather than 1D distance or a 2D plane. It tracks up to 3 targets and supports 4 detection areas plus 4 interference/masking areas; ~6m range, +/-60 deg beam, ~0.4m accuracy. Mount it with the antenna facing the detection area and the pin header along the bottom edge - the reported axes assume that orientation.
- The LD6002B needs a 115200 baud UART (8 data bits, parity NONE, 1 stop bit) with BOTH tx_pin and rx_pin wired. Do not use the ESP's primary/boot UART pins - bootloader chatter on them corrupts the radar's state. ESP32 has 3 hardware UARTs, C3/C6 have 2 - one is usually taken by the logger (UART0).
- This preset keeps it light (presence + count + target 1 position). The component also offers target_2/target_3 X/Y/Z, doppler_index, cluster_id, point_count, per-target and per-area binary sensors, work_mode/ota_version text sensors, and the full config surface (number: hold_delay/z_min/z_max/low_power_sleep_time/area_config, select: sensitivity/trigger_speed/installation_mode/area_id, switch: low_power/point_cloud/target_display, button: apply_area/auto_interference/clear_interference/wake/...). Add those platforms with ld6002b_id: st_ld6002b, or !extend st_ld6002b for wakeup_pin/wakeup_pulse/auto_wake.
